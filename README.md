# 🎂 Cake & Crumbs | Artisanal Home Bakery

A fast, responsive, and aesthetic home bakery web application built with **React 18, Tailwind CSS, and HTML5**. Designed with delicate pastel aesthetics, an interactive custom cake builder, and zero-setup deployment.

🌐 **Live Website:** [cake-and-crumbs.netlify.app](https://cake-and-crumbs.netlify.app)

---

## ✨ Features

- **🍰 Artisanal Cake Showcase:** Curated catalog featuring Korean Bento Cakes, Vintage Lambeth Red Velvet, 100% Eggless specials, and party treats with dynamic category filter pills.
- **🎨 Interactive 60-Second Cake Studio:**
  - Flavor & base selector (Belgian Truffle, Vanilla Bean, Red Velvet, Lotus Biscoff, Pistachio Rose).
  - Aesthetic frosting picker (Vintage Lambeth Frills, Korean Bento, Ombre Buttercream, Semi-Naked).
  - Real-time weight selection and price calculation in ₹ INR.
  - Custom hand-piped message input with a live preview card.
  - Dietary preferences (100% Eggless, Classic, Sugar-Free Stevia).
- **🛍️ Slide-Out Cart & Basket:**
  - Instant item increment/decrement drawer.
  - Subtotal and order summary calculations.
- **💬 Direct WhatsApp Order Dispatch:**
  - Automated WhatsApp order formatting compiling recipient details, delivery address, selected cakes, custom messages, and bill total for instant fulfillment.
- **⚡ Zero-Config Architecture:**
  - Self-contained single-page application powered via CDN React, Babel, and Tailwind CSS without complex build pipelines.

---

## 🛠️ Tech Stack

- **Frontend Library:** [React 18](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **In-Browser Transpiler:** [Babel Standalone](https://babeljs.io/)
- **Icons & Typography:** Google Fonts (*Plus Jakarta Sans*, *Playfair Display*, *Rubik*)
- **Hosting & CI/CD:** [Netlify](https://www.netlify.com/)
